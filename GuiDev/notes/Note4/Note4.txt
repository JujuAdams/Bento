Focus Types:

- Focus
FocusOpen(element, BENTO_FOCUS.POINTER_CANCEL_ALWAYS)

Applies only when using directional input
Must be cancelled using a function call
Automatically cancelled entirely when in pointer mode
No navigation away from focused element
Used to take control of e.g. carousels and scrollers



- Navigate Inside
FocusOpen(element, BENTO_FOCUS.POINTER_CANCEL_ALWAYS)

Applies only when using directional input
Must be cancelled using a function call
Automatically cancelled entirely when in pointer mode
Navigation can only happen inside the focused element
Used to take control of scrollboxes when using keyboard+gamepad input



- Pop-up
FocusOpen(element, BENTO_FOCUS.POINTER_CANCEL_ON_CLICK)

Applies in both directional and pointer modes
Can be cancelled using a function call
Cancelled in pointer mode by clicking off the focused element (or its children)
Navigation can only happen inside the focused element
Used for context menus etc.



- Modal
FocusOpen(element, BENTO_FOCUS.POINTER_CONSTRAIN)

Applies in both directional and pointer modes
Must be cancelled using a function call
Navigation can only happen inside the focused element



- Tabs
FocusOpen(element, BENTO_FOCUS.POINTER_IGNORE)

Applies only when using directional input
Ignored but not cancelled when in pointer mode
Must be cancelled using a function call
Navigation can only happen inside the focused element
Used for restricting interaction when in directional mode



Focusing:
- Always applies in directional mode and may apply in pointer mode
- Can always be cancelled by a function call
- Pointer can do one of three things: always cancel focusing, cancel only when clicking off the focused tree, or never cancel
- Navigation can always only happen inside the focused element
- If an element has no selectable elements, the element itself remains selected
- In one case, pointer can ignore the focus

FocusGetType(element)

BENTO_FOCUS_POINTER_CONSTRAIN
  Pointer is constrained in the same way that directional input is
BENTO_FOCUS_POINTER_IGNORE
  Pointer will ignore the focus but not cancel it. Swapping back to directional mode will re-establish contraints
BENTO_FOCUS_POINTER_CANCEL_ON_CLICK
  Pointer will ignore the focus. Pointer mode can further cancel the focus when clicking outside the focus tree. Swapping back to directional mode will re-establish contraints
BENTO_FOCUS_POINTER_CANCEL_ALWAYS
  Pointer mode will cancel focus immediately when the mode is set
