For most GUI behaviors:
- STEP user event will trigger
- DRAW user event will trigger
- Hoverable in pointer mode (mouse & touch) only
- Clickable in pointer mode only
- Not considered a button by `GuiIsButton()`

Any instance that is set to scrollable by `GuiScrollSetEnabled()` will override any behavior and
will do the following:
- STEP user event will trigger
- Guaranteed to be hoverable in pointer mode
- Guaranteed to be clickable in pointer mode

Otherwise:

GUI_BEHAVIOR_COSMETIC
- STEP user event will not trigger
- Cannot be hovered in any mode
- Cannot be clicked in any mode

GUI_BEHAVIOR_BUTTON
- Can be hovered in any mode
- Can be clicked in any mode
- Considered a button by `GuiIsButton()`

GUI_BEHAVIOR_LISTENER
- As default

GUI_BEHAVIOR_MODAL
- Affects lower priority UI siblings:
  - STEP user event will not trigger
  - Cannot be hovered
  - Cannot be clicked

GUI_BEHAVIOR_POP_UP
- Cannot hover or click UI elements outside of the pop-up in directional mode
- Destroyed if any point outside of the pop-up is clicked in pointer mode (this is regardless of
  the value of `GUI_POP_UP_CLICK_THROUGH`)
- If `GUI_POP_UP_CLICK_THROUGH` is `false`, cannot hover or click UI elements outside of
  the pop-up
- If `GUI_POP_UP_CLICK_THROUGH` is `true`, can hover and click UI elements outside of
  the pop-up

GUI_BEHAVIOR_BLOCK_SIBLINGS
- Affects lower priority UI siblings:
  - STEP user event will not trigger
  - DRAW user event will not trigger
  - Cannot be hovered
  - Cannot be clicked
